# Антифрод-скоринг платёжных транзакций: атака и защита

Финальный проект по дисциплине «Машинное обучение».
Выполнили: Сюткин Е.Р., Прокопович Д.А.

## Что внутри

```
src/
  data.py           генерация синтетического датасета транзакций
  features.py       признаки, разбиение по времени, список управляемых полей
  model.py          обучение HistGradientBoosting, порог по FPR, метрики
  attack.py         атака уклонения: жадная (со скором) и вслепую (5 попыток)
  defense.py        адверсариальное обучение на устойчивых признаках
  service.py        сервис скоринга одной транзакции + лимит отказов
  main.py           запуск всего по порядку
  draw_pipeline.py  схема пайплайна для отчёта
data/               transactions.csv (создаётся при запуске)
models/             baseline.joblib, protected.joblib
results/            results.json и графики
```

## Запуск

```
pip install -r requirements.txt
python src/main.py
```

Полный прогон занимает около минуты на обычном ноутбуке.

## Основные результаты (тестовая выборка)

| | Базовая | Защищённая |
|---|---|---|
| ROC-AUC | 0.984 | 0.977 |
| Recall при FPR ≈ 1% | 0.91 | 0.87 |
| Обход атакой со скором | 52% | 27% |
| Обход за 5 попыток без скора | 50% | 28% |
| Проведено денег от задуманного | 26% | 9% |
| Задержка p95 | 9.6 мс | 8.9 мс |
